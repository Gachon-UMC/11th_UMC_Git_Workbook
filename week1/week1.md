\# 1주차 학습 내용



\## Git 기초

\- git clone: 저장소 복제하기

\- git checkout -b: 새로운 브랜치 생성 및 이동

\- git add: 파일을 staging 영역에 추가

\- git commit: 변경사항 커밋하기

\- git push: 커밋을 원격 저장소에 푸시
